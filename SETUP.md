# Setting up your own shelf

This repo is Meeple & Mug's live catalogue, not the template. It carries the cafe's own
games, branding and nightly sync, so forking it would mean deleting all of that before
you could start.

**The template lives here instead:**
https://github.com/JehanBaguley/shelf-guide-template

Same code, but with a small demo shelf, a setup page that writes your config file for
you, and instructions written for a fresh start. Click **Use this template** there.

While you set yours up, this repo is worth keeping open as the worked example: a real
instance with a few hundred games, full stats and a live sheet behind it.

Live: https://jehanbaguley.github.io/meeple-mug-shelf-guide/
